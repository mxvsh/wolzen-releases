# Wolzen Releases

Public auto-update feed and release binaries for [Wolzen](https://monawwar.gumroad.com/l/wolzen) — beautiful wallpapers for macOS.

The app's source code is private. This repo only hosts:

- `appcast.xml` — Sparkle update feed (served via GitHub Pages)
- GitHub Releases — notarized `.zip` binaries for each version

If you found this repo and want the app, get it on Gumroad: <https://monawwar.gumroad.com/l/wolzen>
